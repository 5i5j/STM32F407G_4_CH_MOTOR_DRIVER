  二、 区分“硬件计数”与“软件采样”

在嵌入式开发中，需要特别区分两个概念：

    硬件脉冲计数 (hardware pulse counting)：STM32 的 硬件定时器编码器模式 (hardware timer encoder mode) 是在硬件后台实时捕获脉冲的。这一过程是无缝且连续的，不占用任何 CPU 资源，因此脉冲计数本身可以说是“无限高频率”的。

    软件采样计算 (software sampling and calculation)：我们所讨论的“编码器 50Hz”，指的是通过 定时器中断读取脉冲差值 (periodic pulse delta reading) 并计算 RPM 转速的软件频率。
